# Telegram-бот поддержки с базой знаний и ИИ

Бот для малого бизнеса (детейлинг, салон, сервис), который отвечает клиентам по прайсу и услугам 24/7, а нестандартные вопросы отдаёт ИИ и запоминает ответ. Собирает заявки, напоминает о себе, присылает владельцу еженедельную сводку.

> Демо-бот с прайсом детейлинг-студии: [@your_demo_bot](https://t.me/) · Подробная инструкция по установке: [docs/SETUP.md](docs/SETUP.md)

## Что умеет

- **Отвечает по базе знаний** — гибридный поиск в SQLite: точное совпадение → полнотекстовый FTS5 → нечёткое сравнение → ИИ-переспрос в «серой зоне». Точность настраивается порогами.
- **ИИ-фолбэк с самообучением** — если ответа нет, вопрос уходит в LLM с контекстом из базы; ответ сохраняется, и в следующий раз отдаётся мгновенно и бесплатно. Кнопки 👍/👎 чистят мусор.
- **Консультант по прайсу** — импорт услуг из CSV, строгий режим «только по каталогу», проверка прайса на противоречия (`/audit`).
- **Сбор заявок** — кнопка «Записаться на осмотр», лиды падают админу, догоняющие сообщения тем, кто спрашивал и пропал.
- **Голосовые** — распознаёт голосовые вопросы клиентов.
- **Рассылки по сегментам** — `/broadcast керамика | текст` уходит только тем, кто интересовался керамикой.
- **Отчёт владельцу** — еженедельная сводка: вопросы, заявки, на что нет ответа.
- **Защита от спама и оффтопа** — лимиты на пользователя, фильтр «не по теме» экономит токены.
- **Тарифы и пробный период** — встроенные `/trial` и `PLAN`, готово к продаже по подписке.

## Стек

Python 3.11+, aiogram 3, SQLite + FTS5, OpenAI-совместимый API (любой провайдер), httpx, systemd-деплой на VPS. Без внешних сервисов и баз — один файл `knowledge.db`.

## Быстрый старт

```bash
cp .env.example .env      # BOT_TOKEN, ADMIN_IDS, AI_API_KEY
pip install -r requirements.txt
python bot.py
```

Windows: `start.bat` создаст окружение и запустит бота. Деплой на сервер: `deploy/install.sh` (systemd-сервис + ежедневный бэкап базы).

## Команды администратора

| Команда | Что делает |
|---|---|
| `/add вопрос \| ответ` | добавить запись в базу |
| `/find текст` | показать, что найдёт бот и с какой оценкой |
| `/leads` | последние заявки клиентов |
| `/audit` | найти услуги с разными ценами |
| `/broadcast [тема \|] текст` | рассылка по базе клиентов |
| `/report [дней]` | сводка владельцу |
| `/export` | выгрузить базу в CSV |
| `/stats` `/settings` `/trial` | статистика, настройки, пробный период |

Наполнение базы: CSV-импорт (`example_import.csv`), команды в чате или автоматически из ответов ИИ.

## Структура

```
bot.py        хендлеры и сценарии aiogram
db.py         схема SQLite, гибридный поиск
ai.py         клиент к LLM (chat + rerank + voice)
config.py     все настройки из .env (~60 параметров)
report.py     еженедельные отчёты
audit.py      проверка прайса на противоречия
voice.py      транскрибация голосовых
trial.py      пробный период и тарифы
test_*.py     тесты сценариев
deploy/       systemd-сервис, установка и бэкапы на VPS
```
